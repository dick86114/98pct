# 意见反馈功能说明

## 功能概述

意见反馈功能允许用户向系统管理员提交使用过程中遇到的问题、建议和意见，帮助平台持续改进。

## 功能特性

### 1. 反馈入口

- **位置**：导航栏右侧，用户头像左边
- **图标**：💬 消息气泡图标 + "反馈"文字
- **权限**：所有登录用户均可使用

### 2. 反馈类型

系统支持四种反馈类型：

| 类型 | 图标 | 说明 |
|------|------|------|
| Bug反馈 | 🐛 | 报告系统错误或异常 |
| 功能建议 | ✨ | 建议新增功能 |
| 改进建议 | 🚀 | 优化现有功能 |
| 其他 | 💬 | 其他意见或建议 |

### 3. 反馈表单

用户需要填写以下信息：

- **反馈类型**：从四种类型中选择一种（必填）
- **标题**：简要描述反馈内容（必填）
- **详细描述**：详细说明问题或建议（必填）

### 4. 反馈状态

反馈提交后会经历以下状态：

| 状态 | 徽章颜色 | 说明 |
|------|----------|------|
| 待处理 | 黄色 | 反馈已提交，等待管理员处理 |
| 处理中 | 蓝色 | 管理员正在处理该反馈 |
| 已解决 | 绿色 | 问题已解决或建议已采纳 |
| 已拒绝 | 灰色 | 反馈不符合要求或无法实现 |

## 管理员功能

### 1. 反馈管理入口

- **位置**：系统管理 → 意见反馈
- **权限**：仅 ADMIN 角色可访问

### 2. 反馈列表

管理员可以查看所有用户提交的反馈，包括：

- 反馈类型
- 标题
- 提交人
- 当前状态
- 提交时间
- 操作按钮（查看详情、删除）

### 3. 反馈详情

点击"查看详情"可以查看完整的反馈信息：

- 反馈类型
- 标题
- 详细描述
- 提交人信息
- 提交时间
- 当前状态

### 4. 处理反馈

管理员可以：

1. **更新状态**：将反馈状态更改为"待处理"、"处理中"、"已解决"或"已拒绝"
2. **添加回复**：在"管理员回复"文本框中输入回复内容（可选）
3. **删除反馈**：删除不需要的反馈记录

## 使用流程

### 用户提交反馈

1. 点击导航栏右侧的"反馈"按钮
2. 在弹出的反馈表单中选择反馈类型
3. 填写标题和详细描述
4. 点击"提交反馈"按钮
5. 系统显示"感谢您的反馈！我们会尽快处理"提示

### 管理员处理反馈

1. 进入"系统管理" → "意见反馈"页面
2. 查看反馈列表，点击"查看详情"按钮
3. 阅读反馈内容
4. 在"管理员回复"框中输入回复（可选）
5. 点击相应的状态按钮更新反馈状态
6. 系统显示"更新成功"提示

## 技术实现

### 数据库模型

```prisma
model Feedback {
  id         Int      @id @default(autoincrement())
  userId     Int
  type       String   // bug, feature, improvement, other
  title      String
  content    String   @db.Text
  status     String   @default("pending") // pending, processing, resolved, rejected
  adminReply String?  @db.Text
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt
  user       User     @relation(fields: [userId], references: [id], onDelete: Cascade)
}
```

### API 路由

- `GET /api/feedback` - 获取反馈列表（管理员查看所有，普通用户查看自己的）
- `POST /api/feedback` - 提交新反馈
- `PUT /api/feedback/[id]` - 更新反馈状态和回复
- `DELETE /api/feedback/[id]` - 删除反馈

### 组件

- `FeedbackModal.js` - 反馈提交弹窗组件
- `Navbar.js` - 导航栏（包含反馈按钮）
- `/admin/feedback/page.js` - 管理员反馈管理页面

## 样式设计

反馈功能采用与平台整体风格一致的设计：

- **反馈按钮**：玻璃态背景，悬停时显示蓝色发光效果
- **反馈类型卡片**：网格布局，选中时显示蓝色边框和背景
- **反馈表单**：清晰的标签和输入框，带有提示信息
- **状态徽章**：不同颜色区分不同状态
- **响应式设计**：移动端自动调整布局

## 注意事项

1. 所有反馈都会记录提交人信息，便于管理员跟进
2. 用户只能查看自己提交的反馈
3. 管理员可以查看和管理所有反馈
4. 删除反馈操作不可恢复，请谨慎操作
5. 建议定期查看和处理用户反馈，提升用户体验
